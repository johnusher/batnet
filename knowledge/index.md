# batnet knowledge bundle

The project's research, decisions and reference material, as an
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
(OKF v0.2) bundle: one markdown file per concept, YAML frontmatter, `type` required.
Rules for adding to it: [knowledge conventions](conventions.md).

# Start here

* [Vision](vision.md) - what batnet is for, who uses it, and how we know milestone 1 works
* [Knowledge conventions](conventions.md) - how concepts, types, trust and freshness are recorded here
* [Glossary](glossary.md) - mesh, LoRa, radio and web terms used across the bundle

# Sections

* [Decisions](decisions/) - architecture decision records, one per choice, with status
* [Research](research/) - what is out there and what the numbers say, with sources
* [Hardware](hardware/) - boards, radios and add-ons, and what each can do
* [Tests](tests/) - bench and field test write-ups; places, people and device IDs stay out
* [Security](security/) - keeping secrets and personal data out of a public repo
* [Skills](skills/) - the agent skills this repo ships, and the ones planned
