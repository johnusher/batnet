# Context

Both options run Meshtastic: a HAT runs it on the Pi as `meshtasticd`, a USB
ESP32 board runs it on the board. batnet talks the same Meshtastic API to either
(TCP to meshtasticd, serial to a board). Every batnet node is an always-on Pi, so
the board's independence from the Pi buys little. See [LoRa radios](/hardware/lora-radios.md).

# Decision

Default: **SPI SX1262 HAT + meshtasticd** (one box, similar or lower cost).
Supported alternative: a **USB Meshtastic board** — for a solar relay with no Pi,
when the GPIO header is taken, or as a second radio.

# Consequences

* Buy SPI HATs only; UART-only HATs do not work with meshtasticd.
* Speech nodes use a USB microphone or speakerphone, not a mic HAT, to keep the header free.
* The installer ships the meshtasticd pin config for each supported HAT.
