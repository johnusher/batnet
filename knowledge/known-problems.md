# Deferred minors (from reviews)

* SQLite gap filling runs one query per entry (plan 1).
* `setup.sh` runs under `set -e`: `touch /etc/cloud/cloud-init.disabled` stops it on an image without `/etc/cloud`, and the hub's restart stops it before pmtiles and the translator if the first start fails. `meshtasticd-override.conf` restarts every 5 s for ever without a radio stick, filling the journal batnetd follows (review 2026-10-22).
* The hand-made protobuf decoder never checks a field's wire type: a wrong type reads as 0 or ""; fuzzed, no crash (review 2026-10-22).
* No test asserts that a silent hello omits `want_response`, nor the hub's sends to a group channel (review 2026-10-22).
* `panel.js` derives a conversation's kind (public, group, direct) in a dozen places from three different tests; one `kind` field would do (review 2026-10-22).
* `batnet-hub.service` could add `ProtectKernelTunables`, `RestrictAddressFamilies` and `SystemCallArchitectures=native`; `setup.sh` could assert no autologin drop-in applies to tty2 for the Terminal button (review 2026-10-22).
* `docs/img/hub/shoot.sh` could refuse `localhost`, where `?redact` leaves the PINs and the WiFi password in the status (review 2026-10-22).
* `OnEntry` can run concurrently in real time; undocumented. The first heartbeat's and `Publish`'s errors are ignored in `main.go` (plan 1).
* Heartbeats carry an address where the spec says node ID (plan 1).
* gitleaks runs in the pre-commit hook only, not in CI (plan 1).
* No meshsync test delivers seq 5 before 4; the forged-entry test uses a fixed sleep (plan 1).
* `hops()` and `channelFor` cost O(n²) per broadcast; the page runs `Judge` twice per frame (plan 2).
* No test of a split and merge under a saturated channel, or of a sender that stays dark (plan 2).
* `TestSeededDeterministic` compares vector lengths, not contents or results (plan 4b).
* The compact author form (`~/<seq>`: an account created by the writing node) is not described in the knowledge bundle yet (plan 4b).
